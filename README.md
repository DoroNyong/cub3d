> C언어와 MiniLibX를 활용하여 레이캐스팅(Raycasting) 원리로 구현한 2.5D 1인칭 탐험 게임

---

## 🖥️ 장르 : 2.5D 1인칭 어드벤처 (싱글 플레이)
Wolfenstein 3D 스타일의 레이캐스팅 기법을 적용하여 2D 맵 데이터를 3차원 공간으로 실시간 투영해 탐험하는 1인칭 게임입니다.

## ⏱️ 개발 기간
- 25.09 - 25.11 (8주)

## 🧑 제작 인원
- 2인 팀 프로젝트 (장현교, 이병한)
- **담당 역할 (장현교)**: MiniLibX 그래픽스 파이프라인, DDA 레이캐스팅 엔진 구현, 텍스처 매핑 및 애니메이션, 키보드/마우스 입력 및 충돌 처리

## ⚙️ 개발 환경
- **Language** : C (C99 / GNU89)
- **Library** : MiniLibX (X11 기반 그래픽 라이브러리), Libft
- **OS** : Linux (Ubuntu / WSL2)
- **IDE** : Visual Studio Code / Vim

---

## 📌 주요 기능

### 맵 파싱 및 사전 유효성 검증
- `.cub` 파일에서 텍스처 경로(NO, SO, WE, EA), 바닥/천장 RGB 색상값, 2차원 맵 데이터를 분리 파싱했습니다.
- 맵 내부가 완전히 벽(`1`)으로 둘러싸여 있는지 검증하고, 유효하지 않은 문자나 빈 공간(공백 누수) 탐지 시 에러 메시지와 함께 자원을 안전하게 해제하도록 예외 처리를 구현했습니다.
- 플레이어 시작 위치(`N`, `S`, `E`, `W`)의 단일성을 보장하고 초기 시선 방향 및 카메라 평면 벡터를 세팅했습니다.

### DDA 레이캐스팅 및 3D 렌더링 파이프라인
- **DDA(Digital Differential Analysis) 알고리즘**을 활용해 각 수직선(화면 너비 픽셀)마다 광선을 투사하고 벽면과의 교차 지점을 실시간 연산했습니다.
- 광선의 유클리드 거리가 아닌 **카메라 평면에 대한 수직 거리(Perpendicular Wall Distance)**를 계산하여 화면 가장자리가 휘는 **어안 왜곡(Fisheye Effect)**을 수학적으로 보정했습니다.
- 수직선 단위로 천장, 벽체, 바닥의 렌더링 영역을 계산하여 프레임 버퍼(이미지 데이터 주소)에 직접 픽셀을 기록하는 방식으로 화면 깜빡임(Tearing)을 방지했습니다.

### 텍스처 매핑 및 애니메이션
- 광선이 충돌한 벽면의 방향(동·서·남·북)을 판별하여 해당 벽면에 맞는 XPM 텍스처를 적용했습니다.
- 벽면 충돌 지점의 소수점 좌표를 텍스처의 가로 인덱스(Tex X)로 변환하고, 벽 높이에 맞게 세로 인덱스(Tex Y)를 보간(Interpolation)하여 1:1 픽셀 매핑을 구현했습니다.
- 텍스처 스프라이트를 배열로 관리하고 일정 프레임 주기마다 텍스처를 순환 교체하여 자연스러운 벽면 애니메이션을 구현했습니다.

### 캐릭터 컨트롤 및 충돌 시스템
- `W`, `A`, `S`, `D` 이동 벡터 연산과 좌우 화살표 키 및 **마우스 회전 감지**(`MotionNotify`)를 통한 부드러운 시점 전환을 구현했습니다.
- 이동하려는 좌표의 타일을 X축, Y축으로 각각 사전 판별하여 벽에 부딪혔을 때 관성이 미끄러지듯 자연스럽게 이어지는 **슬라이딩 충돌(Sliding Collision)** 처리를 적용했습니다.

### 이벤트 및 메모리 관리
- `ESC` 키 입력 및 윈도우 창 닫기 이벤트(Red Cross / Event 17) 발생 시 루프를 안전하게 종료하도록 처리했습니다.
- 프로그램 종료 시 로드된 이미지 버퍼, 윈도우 인스턴스, 2차원 맵 및 텍스처 동적 할당 메모리를 누수 없이 완전하게 해제했습니다.
